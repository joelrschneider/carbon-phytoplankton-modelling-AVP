# carbon-phytoplankton-modelling-AVP

Use Bcalc.ipynb for the biomass-calcification model, and Chemcalc_18sep2026.ipynb for the chemical calcification model. They run using Functions_Bcalc_8okt2026.py and Functions_carbon_18sep2026_3.py, respectively. These python files represent the code for both models.

Statistics.ipynb is used to load the generated output from the model, get statistics for the plots, and make proper plots.
Calc_vs_nocalc.ipynb compares the generated predictions for the biomass-calcification model with a no-calcification situation, using plots.

carbon_ratios.ipynb was used to determine the PON/POC and POP/POC ratios.
POC_SA_relation.ipynb was used to find a relation between POC and phytoplankton surface area.
k_f_calculation.ipynb is an attempt to calculate the k_f.
carbon_calcification_scipy_evo.ipynb was used for automated calibration of parameters.
